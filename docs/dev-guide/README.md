# RAG 平台开发指引 · 总览

> 这是把《项目架构.md》里「六、开发路线图」的 7 个阶段，逐一展开成**小白也能看懂**的开发手把手文档。
>
> **写法约定**（贯穿每个阶段）：
> 1. 每个专业名词第一次出现，都用「人话」解释清楚
> 2. 每个技术都写清「它是什么、原理是什么、为什么选它」
> 3. 复杂原理不硬塞进正文，用 🎓 标注「建议单独学习」，并给学习入口

## 阅读顺序建议

- **想先跑通最小闭环**：P1 → P2 → P3（这三个串起来就是最简 RAG）
- **想深入原理**：每个阶段内部有 🎓 标注的延伸学习
- **想看简历亮点在哪**：P1（增量更新管线）、P4（查询改写）、P6（工程化）、P7（Agent）含金量最高
- **看不懂名词**：查 [《项目架构-术语通俗解释》](../项目架构-术语通俗解释.md)，里面把所有专业名词、指标、数字都用"人话"讲清了；P1 阶段的专属术语表见 [《P1-索引构建-术语通俗解释》](./P1-索引构建-术语通俗解释.md)

## 通用符号说明

| 符号 | 含义 |
|---|---|
| 💡 | 一个直觉/类比，帮你理解 |
| 🎓 | 复杂原理，建议单独学习（会给出入口） |
| ⚠️ | 常见坑，注意绕开 |
| 📋 | 动手要做的事 |
